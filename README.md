# claudioaccolito.github.io

Sito personale, servito da GitHub Pages.

- `index.html` — la home: un giorno intero che scorre con la pagina, e una costellazione da disegnare alla fine (`css/home.css`, `js/sky.js`).
- `now/index.html` — la pagina “now”: per aggiornarla basta modificare le voci della lista e la data.
- `404.html` — pagina non trovata.
- `fonts/` — Fraunces e Inter, ospitati in locale (SIL Open Font License, vedi `fonts/OFL.txt`).

Nessuna dipendenza e nessun build: sono file statici.
